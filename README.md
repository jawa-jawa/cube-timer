# CUBE TIME — ルービックキューブタイマー

スマホ・PC向けのタイム計測アプリです。生成ライブラリを同梱しています。利用者によるビルドやサーバー処理は不要です。

## ファイル

- index.html：アプリ本体。
- scrambler.js：3×3スクランブル生成と短すぎる状態の除外。
- vendor/：生成ライブラリと必要な依存ファイル。フォルダ構成を保って配置してください。
- package.json：ローカル検証用のモジュール指定。
- README.md：この説明書。

## 操作

1. 画面のスクランブルを見て、完成状態の3×3キューブを混ぜます。混ぜ終わったらスタートで計測を開始します。
2. 完成したらストップを押します。成功タイムを自動で記録します。
3. 完成できなかったら計測中に失敗を押します。DNFとして記録します。

時刻は分:秒.百分の一秒で表示します。PCではボタンや入力欄にフォーカスがない状態でスペースキーでも開始・停止できます。
誤った記録は履歴から個別に削除できます（確認あり）。
過去のテスト記録を削除するには「挑戦の記録」で「古い順」に切り替え、履歴内をスクロールして対象にチェックし、「選択した記録を削除」を押します。ヘッダーのチェックは全記録を選択します。
削除前に件数と対象日時を確認できます。計測中は削除できません。削除するとグラフ・平均・自己ベストが再計算されます。取り消しはできないため、必要なら事前にCSV保存してください。端末保存に失敗した場合は削除を取り消します。
削除はこの端末の記録に対する操作です。他端末の記録や以前保存したCSVは変更されません。

## 集計とグラフ

- 自己ベスト・平均は成功した記録だけで計算します。平均は単純平均です。
- DNFは挑戦回数と失敗回数に含め、平均タイムには含めません。
- グラフは縦軸が秒、横軸が挑戦番号です。直近30回・100回・全記録を切り替えられます。
- DNFを×で表示し、その位置で線を途切れさせます。
- 挑戦番号は現在の履歴順で付け直されます。

## GitHubへの配置

ZIPを解凍し、index.html・scrambler.js・vendorフォルダを含む全ファイルを公開フォルダに配置してください。フォルダ構成を変えないでください。ZIPファイル自体を配置してもアプリは開けません。
GitHub Pagesの公開対象フォルダとindex.htmlの配置先を一致させてください。
公開されたHTTPSのURLをスマホのSafariやChromeで開いて利用します。
このアプリにアカウント登録やGitHubへのログインは必要ありません。

## 記録とバックアップ

記録はlocalStorageを使い、利用端末のブラウザ内に保存します。記録をGitHubや外部サーバーへ送信する機能はありません。
別の端末やブラウザとは自動同期しません。ブラウザのデータ削除やプライベートブラウズの終了で記録が失われる場合があります。

### 別のスマホへの移行・記録の合流

1. 元のスマホで「CSV保存」を押し、ファイルを保存します。「CSVを共有」対応端末では共有画面から直接送れます。
2. AirDrop、メール添付、クラウドのファイル共有などで、CSVをもう一方のスマホへ送ります。
3. 受信側でCSVをファイルアプリやダウンロードフォルダに保存します。
4. 受信側のスマホで公開済みアプリを開き、「CSV・旧バックアップ読込」からCSVを選びます。
5. 追加件数を確認してOKを押すと、既存記録に追加され、グラフ・集計も更新されます。

同じ記録は記録IDで判定してスキップするため、同じCSVを何度読み込んでも重複しません。同じ日時・タイムでも別IDの挑戦は別記録として残します。
両方の端末の記録をそろえるには、合流後の端末でCSVを保存し、もう一方にも読み込んでください。自動同期ではありません。削除操作は他端末へ同期されず、削除した記録がCSVにあれば再追加されます。
従来のJSONバックアップも同じ読込ボタンで取り込めます。読み込みエラー時はファイル全体を取り込まず、既存記録を維持します。

### CSV形式

UTF-8（BOM付き）、カンマ区切り、CRLF改行です。
列は record_id / recorded_at / elapsed_ms / result / time / scramble の順です。
recorded_at はUTCのISO日時（画面表示は端末の現地時刻）、elapsed_ms はミリ秒、result は ok または dnf、time は見やすい表示用、scramble は使用した混ぜ方です。旧5列CSVも読み込めます。
移行にはアプリから保存したCSVを編集せず使用してください。Excelなどで編集するとIDや日時の形式が変わることがあります。
読み込み上限は10MBです。共有できないブラウザではCSVのダウンロードに切り替わります。

アプリを同じ公開URLで更新する場合は通常、既存記録を引き継ぎます。変更前にバックアップを推奨します。
同じブラウザの複数タブで同時利用しないでください。

## 計測について

画面が背面に移っても経過時間に含めます。再読み込み時は保存された開始時刻から計測を復元します。
対応ブラウザでは計測中の画面消灯を防止しますが、OSの制限などによって機能しない場合があります。
端末時計の変更は計測に影響します。公式大会用の計測器を代替するものではありません。
通信なしでも読み込み済みの画面は使用できますが、オフラインでの再起動を保証するPWAではありません。

## スクランブル（3×3専用）

起動時と各計測の終了後に次の混ぜ方を生成します。生成が終わるまでスタートは無効です。「別の手順にする」でも変更できます。混ぜている間は計測しません。計測中の手順変更はできません。
完成状態で白を上、緑を手前にして、左から回してください。標準配色以外の持ち方はWCA 4d1を参照してください。失敗後はいったん完成状態に戻してから混ぜます。
R/L/U/D/F/B＝右/左/上/下/手前/奥。各面を正面から見て、文字だけは時計回り90°、'は反時計回り90°、2は180°です。
履歴の「混ぜ方」で使用手順を再確認できます。CSVにも保存します。旧記録には手順がありません。

WCA規則のランダム状態方式・回転記号を参考に、cubing.js 0.66.1 の randomScrambleForEvent('333') で生成します。アプリ側で完成状態と1手で解ける18状態を除外します。単に25回ランダムに回す方式ではありません。
本アプリは練習用であり、WCA公認の公式大会用生成ソフトではありません。公式大会は指定されたTNoodleを使用してください。15秒のインスペクションや大会の罰則判定は実装していません。

参照（2026-10-18確認）：
- https://www.worldcubeassociation.org/regulations/#4b3
- https://www.worldcubeassociation.org/regulations/#4d1
- https://www.worldcubeassociation.org/regulations/#12a1
- https://www.worldcubeassociation.org/regulations/scrambles/
- https://js.cubing.net/cubing/scramble/

GitHub PagesなどHTTPSで開いてください。file://で直接開くとモジュール・Workerの制限により生成できません。生成失敗時はエラーと再試行ボタンを表示します。旧バージョンと同じ保存キーなので、同じサイト・ブラウザで更新すれば既存記録を引き継ぎます。
